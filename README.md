# Client Database Cleaning (Excel Project)

## Project Overview

This project demonstrates the cleaning and organization of a messy client database using Microsoft Excel.

The goal was to transform raw, inconsistent client information into a clean, structured, and easy-to-use dataset.

## Objective

* Clean and standardize client information
* Remove unnecessary spaces and inconsistencies
* Standardize names and email data
* Improve data accuracy and readability
* Prepare the dataset for further analysis or business use

## Cleaning Tasks

* Removed extra spaces from text data
* Standardized name formatting
* Cleaned and organized email addresses
* Improved consistency across records
* Structured the cleaned data for easy use

## Excel Skills Used

* Microsoft Excel
* Data Cleaning
* Data Formatting
* Data Organization
* Text Cleaning
* Data Quality Improvement

## Workbook Structure

### Raw_Data

Contains the original client data before cleaning.

### Clean_Data

Contains the cleaned and standardized client data after the cleaning process.

## Project Result

The final workbook provides a cleaner, more consistent, and organized client database that is easier to read, manage, and use for further analysis.
